uBuddy CORE INTERFACES

uBuddy 核心界面与任务执行看板指南

覆盖私聊、正确的公共任务群聊、单联系人任务发布、多人任务发布、任务卡内部节点，以及任务工作区的动态、结果、流程图、技术详情和失败诊断。

截图数据：隔离演示账号与合成任务，不包含真实聊天、联系人或项目内容
完整版手册保持不变

本手册包含什么

  1. uBuddy 私聊界面
    用于直接告诉 uBuddy 目标、切换 Task/Ask、选择 Agent、项目、Memory、权限并发送任务。
  2. 公共任务群聊界面
    多人协作时的公开沟通区域。群消息、共享目标、成员和公开任务进度对群成员可见。
  3. 单个联系人任务发布界面
    将任务交给一个明确联系人及其 uBuddy。系统不会仅凭聊天历史自动选择接收人。
  4. 多人任务发布界面
    uBuddy 根据任务目标拆分多人分工，并在真正派发前让发起人确认或修改。
  5. 已发布任务卡及内部节点
    任务发布后显示当前负责人、总体进度和公开节点。截图已展开任务卡内部的“公开节点状态”，可看到已完成节点、执行中节点和完成比例。
  6. 任务执行看板：动态
    集中展示当前状态、执行节点、过程记录、补充消息和底部任务沟通输入框。
  7. 任务执行看板：结果
    查看当前交付版本、质量检查建议、交付文件和验收入口。
  8. 任务执行看板：结果内部详情
    展示结果卡内部展开后的质量建议、正文和文件详情，便于核对任务卡内部信息。
  9. 任务执行看板：流程图
    按节点展示任务拆解、依赖关系、负责人和每个节点的执行状态。
  10. 任务执行看板：技术详情
    展示任务、节点和执行事件的技术级信息，用于排查执行问题。
  11. 任务执行看板：失败诊断
    任务失败时显示最后一次报错、失败节点、相关命令和可恢复信息。

红色编号与按钮表一一对应。只介绍与 uBuddy 工作流直接相关的按钮，不扩展普通账号设置、星标或备注等宿主功能。

4. 多人任务发布界面

04-multi-task-publish.png

uBuddy 根据任务目标拆分多人分工，并在真正派发前让发起人确认或修改。

按钮说明

编号按钮或控件点击后发生什么
1确认派发按照当前多人分工创建并派发任务。
2修改返回规划流程，补充修改要求并重新生成分工。
3全员参与覆盖自动筛选，让所有候选参与本次任务。
4取消取消本次多人协作方案，不派发任何任务。

最短操作流程：检查每位参与者的分工 → 必要时修改或改为全员参与 → 点击“确认派发”创建任务。
